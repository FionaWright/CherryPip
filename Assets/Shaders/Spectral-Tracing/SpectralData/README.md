# Spectral Data

This directory contains various spectra that are used for spectral-rendering

## CIE 2006

This contains the CIE 2006 XYZbar and spectral primaries data

CIE2006_Cheb applies Chebyshev curve fitting to the spectral primaries, unused

CIE2006_Logistic applies Logistic curve fitting to the spectral primaries

CIE2006_MLG applied Multi-Lobe Gaussian curve fitting to XYZbar

## D65 Standard Illuminant

This contains the D65 standard illuminant data

D65_MLG applies Multi-Lobe Gaussian curve fitting to the data

## IOR

Contains Sellmeier curve fit dielectric/glass reflective index spectra, and raw complex conductor reflective index spectra
